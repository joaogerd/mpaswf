# x1.10242 MPAS forecast contract

This document records the forecast layer that follows the validated MPASWF
`prepare` and `init` phases on JACI.

## Scope

For the reference campaign:

- valid times: 2026-06-22 00Z through 2026-06-25 00Z, every 24 h;
- forecast leads: f024 and f048;
- unique forecast jobs: 8;
- MPI ranks: 128 on one exclusive node;
- `config_dt`: 60 s;
- MPAS/JEDI output interval: 24 h.

The forecast phase consumes the five already validated initialized states from
2026-06-20 00Z through 2026-06-24 00Z.

## Runtime inputs

The reference forecast directory is assembled from these sources:

1. the initialized state produced by MPASWF, linked as `init.nc`;
2. the validated x1.10242 invariant, linked as `x1.10242.invariant.nc`;
3. x1.10242 grid, graph and `graph.info.part.128` files;
4. MPAS physics/runtime tables from
   `${MONAN_JEDI_INSTALL_ROOT}/share/MPAS/core_atmosphere`;
5. the 240-km `namelist.atmosphere_240km`, `streams.atmosphere_240km` and
   JEDI stream lists from the same MPAS-JEDI tutorial input set used by the
   previously validated NMC workflow.

The installed `mpas_atmosphere` executable is always resolved from
`${MONAN_JEDI_INSTALL_ROOT}/bin/mpas_atmosphere`.

## Rendered namelist settings

MPASWF patches only the run-dependent settings already exercised by the
previous x1.10242 NMC workflow:

- `config_dt = 60.0`;
- `config_start_time` = forecast initialization time;
- `config_run_duration` = 1 or 2 days;
- `config_do_restart = .false.`;
- `config_block_decomp_file_prefix = 'x1.10242.graph.info.part.'`;
- SST/deep-soil updates disabled;
- `config_do_DAcycling = .true.`;
- `config_jedi_da = .true.`.

The remaining scientific settings come from the validated 240-km reference
namelist and are not reconstructed by MPASWF.

## Streams

The reference streams are patched to guarantee:

- invariant input: `x1.10242.invariant.nc`;
- initial state input: `init.nc`;
- JEDI `da_state` output: `mpasout.$Y-$M-$D_$h.$m.$s.nc`;
- `packages="jedi_da"`;
- restart output: `restart.$Y-$M-$D_$h.$m.$s.nc`;
- 24-hour output interval;
- overwrite-safe reruns;
- ordinary history/diagnostics disabled for this NMC-production path.

## Preflight

Before `qsub`, the JACI reference case fails if any of these are missing or
inconsistent:

- initialized state;
- invariant;
- grid, graph and 128-rank partition;
- required MPAS physics tables;
- analysis/background/control/ensemble stream lists;
- critical namelist settings;
- `da_state` and restart stream definitions.

## PBS resources

The JACI reference configuration uses:

- queue `pesqmidi` for forecasts;
- one exclusive node, 128 ranks;
- f024 walltime: 01:00:00;
- f048 walltime: 02:00:00;
- the same validated spack-stack/JEDI bootstrap already proven by `pbs-smoke`
  and the five successful `mpas_init_atmosphere` jobs.

## Acceptance

A forecast is accepted only when:

1. the expected restart NetCDF exists and passes file validation;
2. the expected `mpasout`/`da_state` NetCDF exists and passes file validation;
3. `log.atmosphere.0000.out` exists;
4. the MPAS log reports zero critical errors and zero ordinary errors.

After all eight forecasts pass, the `manifest` phase must validate the four
same-valid-time f048/f024 pairs and write `products/mpas-forecast-manifest.tsv`.
